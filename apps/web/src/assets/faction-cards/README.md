# Risk Legacy faction-card scans

The JPGs in this directory are physical faction-card textures used by the public
Tabletop Simulator workshop item `620524853`. The five base-faction files are
rotated extracts. `mutants.jpg` and `aliens.jpg` retain their portrait-first source
orientation and are rotated non-destructively by the card component.
They preserve the original Hasbro card artwork for this private campaign tool.

Workshop source:
`https://steamcommunity.com/sharedfiles/filedetails/?id=620524853`
